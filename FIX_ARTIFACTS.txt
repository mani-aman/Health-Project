🎯 SUMMARY
──────────────────────────────────────────────────────────────────────────────

Error: "Cannot set property query of #<IncomingMessage> which has only a getter"

Root Cause: express-mongo-sanitize v2.2.0 attempted to assign req.query in
            Express 5.2.1 where it's a getter-only property

Solution: Remove express-mongo-sanitize and rely on superior data-layer
         validation through Mongoose schema validation

Impact:
  • Protected Admin login now works ✅
  • All query parameter endpoints work ✅
  • Security improved (data-layer > HTTP-layer) ✅
  • No regressions detected ✅
